# Ортеко — прототип

Прототип системы учёта заявок, склада и актов для кейса «Ортеко» (сервис оборудования для кафе и ресторанов).

**Демо:** https://dimkassik.github.io/orteko-prototype/

## Экраны
1. **Где деньги** — панель руководителя: сколько денег застряло между «работа сделана» и «оплата получена», дебиторка по клиентам и срокам, просрочки и дефицит склада.
2. **Заявки** — все заявки по шагам пути «заявка → выезд → акт → счёт → оплата».
3. **Карточка заявки** — работы, выдача запчастей со склада (только под заявку), подпись акта, счёт и оплата.

Данные демонстрационные и хранятся в браузере; кнопка «Сбросить демо» возвращает исходное состояние.

## Запуск
```bash
npm install
npm run dev
```
Публикация на GitHub Pages: `npm run deploy`.
