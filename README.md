# Ортеко — прототип

Прототип системы учёта заявок, склада и актов для кейса «Ортеко» — сервис оборудования для кафе и ресторанов.
Оборот вырос почти вдвое, а денег на счёте столько же: заявки, склад и акты теряются.

**Демо:** https://dimkassik.github.io/orteko-prototype/

## Идея
Каждая заявка проходит путь «заявка → выезд → акт → счёт → оплата» в одной системе.
Владелец видит, на каком шаге застряли деньги. Три роли работают с общими данными: действие одной сразу видно остальным.

## Экраны
| Роль | Что видит и делает |
|---|---|
| **Владелец — «Где деньги»** | Сколько заработано, но не получено; деньги по шагам «нет акта → нет счёта → нет оплаты»; график «начислено и получено» по месяцам; дебиторка по возрасту; какой инженер не закрывает акты. Счёт выставляется одной кнопкой |
| **Диспетчер — «Заявки»** | Доска заявок из звонков, WhatsApp и почты с таймером срока реакции по договору; нагрузка инженеров; новая заявка с оборудованием клиента и гарантией |
| **Инженер — телефон** | Заявки на день, работы, поиск и выдача запчасти со склада, акт и подпись клиента пальцем на экране |

Плюс **сценарий демо** (8 шагов) и **отзывы сотрудников**: журнал «что просили и что уже сделано» — работа короткими циклами по 2–4 дня.

Данные демонстрационные и хранятся в браузере; «Сбросить демо» возвращает исходное состояние.

## Стек и запуск
React + Vite, без бэкенда (прототип). Иконки — lucide-react.
```bash
npm install
npm run dev
```
Публикация на GitHub Pages: `npm run deploy`.
